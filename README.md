# Лабораторная работа №1. Основы HTML и структура веб-страницы

**Вариант 6:** Любитель кино и сериалов.

## Описание
Страница «О себе» содержит:
- Шапку (`<header>`) с именем и заголовком.
- Основной контент (`<main>`) с двумя секциями:
  - «Навыки» — маркированный список.
  - «Проекты» — нумерованный список из 4 пунктов.
- Боковую панель (`<aside>`) с любимым режиссёром и жанром.
- Изображение-аватар с атрибутами `src`, `alt`, `width`, `height`.
- Форму обратной связи с полями «Имя», «Email», «Сообщение» и кнопкой отправки.
- Подвал (`<footer>`) с копирайтом и годом.
